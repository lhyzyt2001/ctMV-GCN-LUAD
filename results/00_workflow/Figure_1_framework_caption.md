**Figure 1. Overview of the ctMV-GCN framework and validation strategy.** (a) Cell-type expression profiles aggregated from TISCH are integrated with three disease-independent graph views: STRING functional associations, cell-type similarity and shared-pathway relationships. Feature scaling and five-component principal component analysis are fitted using training nodes only. Each graph view is encoded by two weighted graph convolutional layers, and node-specific local attention weights combine the three branch embeddings before a linear classifier estimates clinical-evidence probability using class-weighted cross-entropy. (b) Predictive performance is evaluated using transductive repeated five-fold cross-validation (three repeats) with a 15% inner validation split; outer-test labels are hidden while all nodes and graph topology remain visible. Comparators include random walk with restart (RWR), degree, logistic regression (LR), random forest (RF), GCN, graph attention network (GAT), GraphSAGE and GNN ablations; metrics are ROC-AUC, AUPRC and Top-K recovery. (c) Ten fixed-seed models are summarized by mean score, rank standard deviation and Top-500 frequency. Post hoc degree/structural filtering is followed by a robustness score combining degree-residual percentile (0.50), Top-500 frequency (0.25) and rank-stability percentile (0.25) to define the robust Top 20. (d) The same robust candidate set is characterized using TCGA-LUAD expression, stage, overall survival and new-tumor-event endpoints, gene set enrichment analysis (GSEA), GSE68465 expression and survival, CPTAC tumor protein profiles and DepMap LUAD CRISPR dependency. False-discovery rates are controlled within each endpoint. External outcomes are not used for candidate selection; observed associations do not establish therapeutic efficacy or causality.

Abbreviations: AUPRC, area under the precision–recall curve; CE, cross-entropy; CPTAC, Clinical Proteomic Tumor Analysis Consortium; GCN, graph convolutional network; GSEA, gene set enrichment analysis; LUAD, lung adenocarcinoma; PCA, principal component analysis; ROC-AUC, area under the receiver operating characteristic curve; STRING, Search Tool for the Retrieval of Interacting Genes/Proteins; TCGA, The Cancer Genome Atlas.
